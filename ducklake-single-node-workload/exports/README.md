# Static notebook exports

These are source-free static marimo HTML snapshots captured during the measured runs used by the study. They preserve displayed output without executing the workload again.

The quick files come from the median measured quick run. The large files come from the median measured large run.

`pipeline` shows the root notebook and nested activity results. `results` shows the publishing notebook with the measurement table and generated chart. GitHub displays the HTML source; use the rendered links in the project README to view the snapshots. The hosted pages load pinned, self-hosted marimo frontend assets.
