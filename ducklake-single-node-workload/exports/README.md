# Static notebook exports

These are static marimo HTML exports captured during the measured runs used by the study. They preserve notebook source and displayed output without executing the workload again.

The quick files come from the median measured quick run. The large files come from the median measured large run.

`pipeline` shows the root notebook and nested activity results. `results` shows the publishing notebook with the measurement table and generated chart. Open them locally in any modern browser. The files load marimo's frontend assets from its public CDN.
