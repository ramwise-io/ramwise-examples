# Static notebook exports

These are self-contained marimo HTML exports captured during the same retained Anatini Runs used by the study.

The quick files come from Run `0eccec38-87ae-4b07-919e-3d41d38661ea`, the median measured quick Run. The large files come from Run `85e7b5f3-3f42-4845-b3f8-3b40a66f7910`, the median measured large Run.

`pipeline` shows the root notebook and nested activity results. `results` shows the publishing notebook with the measurement table and generated chart. Open them locally in any modern browser.
