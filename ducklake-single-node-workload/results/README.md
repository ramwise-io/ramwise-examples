# Derived results

- `run-index.csv` — all indexed warm-up and measured runs with duration, timed work, runner overhead, resources, snapshots, and check counts;
- `all-measurements.csv` — seven workload-step observations per indexed run;
- `profile-summary.csv` — five-run median/minimum/maximum by scale profile;
- `step-summary.csv` — five-run summary by scale profile and workload;
- `analysis-summary.json` — machine-readable top-line result.

These are deterministic derived artifacts, not manually edited spreadsheet summaries.
